## 📌 About The Project

A clean and fully functional **Personal Finance Tracker** web app built using pure **HTML, CSS and JavaScript** — no frameworks, no backend, just vanilla JS doing all the heavy lifting.

Designed with a modern **dark theme**, this app helps you track your daily income and expenses, visualize your spending habits with a **live pie chart**, and filter transactions by category — all while saving your data locally so nothing is lost on refresh.

---

## ✨ Features

- ➕ **Add Income & Expenses** — with description, amount, category and date
- 📊 **Live Pie Chart** — spending breakdown by category using Chart.js
- 💰 **Summary Cards** — real-time balance, total income and total expenses
- 🔍 **Filter Transactions** — filter by All, Income, Expense or specific categories
- 🗑️ **Delete Transactions** — remove any entry with one click
- 💾 **localStorage Support** — data persists even after closing the browser
- 🔔 **Toast Notifications** — instant feedback on every action
- 📱 **Fully Responsive** — works on mobile, tablet and desktop
- 🌙 **Dark Theme** — easy on the eyes with a professional look

## 🚀 Getting Started

### Option 1 — Open directly
Just download the project and open `index.html` in your browser. No setup needed!

### Option 2 — VS Code + Live Server
```bash
# Clone the repo
git clone https://github.com/sumitkumar98313/finance-tracker.git

# Open in VS Code
cd finance-tracker
code .

# Right click index.html → Open with Live Server
```
